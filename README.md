## 🛠️ Documentation Strategy & Standards

- **Single Source of Truth per Topic:** Each topic contains exactly **one primary `README.md`** that serves as comprehensive, living documentation. Assignments do not create separate detached README files; instead, they are consolidated into the topic's main guide.
- **Educational Depth:** Explanations emphasize the *why* behind syntax, commands, and tools rather than merely listing instructions or questions.
- **Preservation & Integrity:** Source files and compiled outputs (e.g., generated PDFs, HTML trees) reside together within their respective `assignments/` directories.
- **Verifiable Outputs:** All compilation commands, tools, and outputs are thoroughly verified before documentation.
